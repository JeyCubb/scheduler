# Schedule Creator

A standalone, real-time interactive visual schedule creator and section planner with time conflict collision detection.

## Features
- **Visual Timetable Calendar**: Dynamic day (Monday–Friday) grid with hourly time-slot matching.
- **Section Collision Detection**: Highlights overlapping time slots with conflict badges, warnings, and partner highlights on hover.
- **Block Presets**: Fast-load recommended blocks (Choice A, Choice B) or clear all sections.
- **Responsive Layout**:
  - Full desktop 100vh level dual-panel layout.
  - Mobile phone zoom-out view where the complete 5-day week fits cleanly on smaller screens.
- **Cross-App Navigation**: Integrated with [TIP Grade Calculator](https://jeycubb.github.io/TIP-Grade-Calculator/) and [JeyCub Terms Reviewer](https://jeycubb.github.io/JeyCub-terms-reviewer/).
- **Theme Support**: Seamless Dark / Light mode toggle with persistent preferences.
